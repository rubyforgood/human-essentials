Import, Export, and one glyph per meaning

You are right: the arrows point the wrong way. Import carries an arrow leaving a tray and Export carries one entering it — two directional words over two arrows pointing the opposite way. The audit found six more disagreements behind it.

1. What is actually on screen

The header of /donation_sites, exactly as it renders today. The glyphs below are the two icons at 34px so the direction is unmistakable.

Donation sites

bi-upload arrow OUT — on Import
bi-download arrow IN — on Export
Import points out. Export points in. Both are backwards.

There is a reason it happened, and it is not carelessness. Two frames of reference collided. Upload / download is measured from the server: up to it, down to you. Import / export is measured from the app: in to it, out of it. The buttons say import and export; the icons are named upload and download. Whichever frame you read it in, half the row is inverted.

2. What the systems that ship both do

Fetched from the source repositories this morning and rasterised, not recalled. Shopify Polaris and IBM Carbon both ship a named Import/Export pair, and both draw export as an arrow going up and out, import as an arrow coming down and in. Carbon ships export and download as separate icons, so it is explicit that an export is not a download.

3. Three ways out

Option A — match the frame to the word recommended

Import and export are movements in and out of a box, so they get the in/out-of-a-box arrows. This is Polaris and Carbon exactly. Bootstrap Icons already ships the pair, and bi-download stays free to mean a literal download — which the same page uses for Download example CSV.

Donation sites

bi-box-arrow-in-down into the box — Import
bi-box-arrow-up out of the box — Export
bi-download stays on Download example CSV
Word and arrow agree. Three meanings, three glyphs.
  • For: what the two systems that ship the pair both do; leaves bi-download meaning download and nothing else; the class name reads like the button.
  • Against: two glyphs the app has not used before.

Option B — swap the two it already has smallest change

Donation sites

Arrows now agree with the words — but the source reads icon: "bi-download" on the Import button, and bi-download ends up on both Import and Download example CSV on the same page.
  • For: two lines per call site, no new glyphs.
  • Against: a name that contradicts its use is a trap for whoever edits it next — this is the same class of fault as the one you spotted, moved from the screen into the source.

Option C — change the words instead

Donation sites

Consistent, and honest about what the browser does — but it retires “Export”, which is on 18 buttons, in the menu on /requests, and in the partner-facing copy.
