Design review

Five things wrong on the partner pages

Measured on /partners/2 and /profiles/2/edit at 1440 px. Four have one right answer. One is a genuine choice.

01

The badge is inside the actions slot

Defect

The page header's [data-page-header="actions"] container holds exactly two children: a SPAN reading “Approved”, and the Deactivate form. A status is not an action — so a pill sitting in a row of buttons reads as a button that has been greyed out.

Now

Pawnee Homeless Shelter
Partner administration.
ApprovedDeactivate partner

Status and action in one row, reading as two controls — one of them broken.

Proposed

Pawnee Homeless Shelter Approved
Partner administration.
Deactivate partner

Status belongs to the thing, so it sits with its name. The actions slot holds only actions.

Needs a status: slot on the page-header partial — which nothing in the app has today, and which every other entity page could then use.

A native <dialog> centres itself through the browser's own margin: auto. This one is rendered inside a space-y-6 container, and that container's spacing rule lands on the dialog and replaces the auto margins.

One sub-question is genuinely yours. “Save progress” is a second submit that saves without leaving, which is worth keeping on a thirteen-section form — but two submits side by side, one of them primary, is ambiguous. Keep both with the primary clearly last, or drop it and let each section save itself. I would keep it: a long form you can only save by finishing is worse.

Recommendation

All five. Only 02 is a real choice.

  1. Status pill onto the title line, out of the actions slot — via a new status: slot other entity pages can share.
  2. “See all 13” inside the Zipcodes card, unless you would rather have the Service-area card.
  3. Edit details and Manage users into the card header, the pattern already used by “Prior distributions”.
  4. Fix modal centring in the shared partial, so no ancestor's spacing can move a dialog again.
  5. Edit partner profile onto the page gutter: one action row at the end, real button helpers, and drop the icon that repeats ten times.
