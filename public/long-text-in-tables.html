Long text in a table column

Measured on /purchases: rows are 145 to 245px where a table row is normally about 45px, and fourteen rows make a 2,711px table. One column is doing all of it. The figures under each panel are measured from this page.

What the row height is for

A table's value is that rows are comparable at a glance.

Predictable row height is not decoration — it is the thing that lets the eye run down a column and compare. A free-text field has no length limit, so a cell holding one sets the row height to whatever somebody typed, and fourteen purchases become a page you scroll rather than a table you read.

Every design system says the same thing. Carbon: truncate, and put the full value on the detail page. Material, Salesforce Lightning (slds-truncate), Atlassian, Stripe, Linear and GitHub all clip to one line. Polaris and Notion allow two. Nobody lets the cell grow.

Recommendation

Option B, as a .notes column class. The design system already types its columns — .numeric, .quantity, .date — and this is the fourth kind of column the app has: free text of unbounded length. A class rather than a utility string is what stops the next long-text column arriving at a different width.

The full text is not lost, and that is what makes clipping safe here. CSS clipping leaves the whole string in the DOM, so a screen reader still reads all of it — and every one of these rows already has a View action leading to a page where the comment is shown in full. Nothing becomes unreachable; it becomes one click away.

No title tooltip. It is the obvious addition and it is the same trap as the icon button two rounds ago: not shown on keyboard focus, absent on touch, and announced on top of the text it duplicates.

C was the near miss. Two lines reads generously, but a column that is sometimes one line and sometimes two gives the table two row heights, which is most of the problem in miniature. D is right for any of the eighteen columns that turn out to be almost always empty — worth checking per table rather than assuming.
